# Decision pending: DB++ successor brand

Date: 9 October 2026
Status: **Candidate only, not cleared or approved for release**

The preferred proposed public name is **DB++**, because it communicates an
evolution of dBASE in the familiar C/C++ naming idiom. The existing XABL
repository, code symbols, executable and build metadata MUST retain their
present names until legal/brand clearance and an explicit rename decision.

Known prior software uses:
- db++ relational DB by Concept asa, referenced by the PHP/PECL dbplus
  extension, which PECL identifies as unmaintained:
  https://pecl.php.net/package/dbplus
- Other historical DB++ C++ database-abstraction projects.
- Historical German trademark proceedings involving a db++ mark.

These historical uses do not by themselves establish present ownership,
registrations, abandonment, freedom to operate or non-infringement.

Before approving a public rename:
1. Obtain an authoritative UK IPO search of active/pending exact and similar
   marks, including DB++, DB PLUS, DBPLUS and relevant stylisations.
2. Check EUIPO, WIPO and USPTO live registers for relevant software and
   software-development services (notably Nice classes 9 and 42).
3. Verify present status and proprietor of any earlier relevant German mark,
   and investigate unregistered commercial usage where appropriate.
4. Confirm domain registration and actual registrability for suitable
   spelling variants, GitHub organisation/repository identifiers, common
   executable names and package registry names.
5. Seek appropriately qualified trademark advice if conflicts remain; document
   the owner's express selection and migration plan before making changes.

Official UK search:
https://www.gov.uk/search-for-trademark

No trademark filing, domain acquisition or public code rename is authorised by
this document.
